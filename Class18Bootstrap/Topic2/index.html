Login Form Example

In a login page, margin creates space between form sections, while padding creates inner space inside input boxes and buttons.

Concept Explanation

1. Margin: Space outside an element.

2. Padding: Space inside an element.

3. Difference: Margin separates elements; padding creates inner spacing.

4. Margin Syntax: m{side}-{size}

5. Padding Syntax: p{side}-{size}

6. px-5 vs py-5: px = horizontal padding, py = vertical padding.

7. Bootstrap Advantage: Faster, cleaner, reusable classes without writing extra CSS.
