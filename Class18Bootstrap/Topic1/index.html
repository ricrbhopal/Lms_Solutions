Bootstrap Borders, Rounded & Shadows

  1. Purpose of the border class:
    The border class adds a border around an element.
  2. Border classes for specific sides:
    border-top, border-bottom, border-start, border-end
  3. What does border-top do?
    It adds a border only to the top side of an element.
  4. Use of border-primary:
    It changes the border color to Bootstrap’s primary color (blue by default).
  5. Difference between border-1 and border-5:
    border-1 creates a thin border, while border-5 creates a much thicker border.
  6. Purpose of the rounded class:
    It adds rounded corners to elements.
  7. What does rounded-0 mean?
    It removes all rounded corners, making edges sharp.
  8. Difference between rounded-circle and rounded-pill:
    rounded-circle makes the element circular.
    rounded-pill makes the element oval/pill-shaped.
  9. Where is rounded-pill commonly used?
    It is commonly used in buttons, badges, tags, and capsules.
  10. Purpose of shadow classes:
    Shadow classes add depth and visual elevation to elements.
  11. Difference between shadow-sm, shadow, and shadow-lg:
    shadow-sm = Small shadow
    shadow = Normal shadow
    shadow-lg = Large shadow
  12. What does shadow-none do?
    It removes any shadow from an element.
  13. Why are borders, rounded corners, and shadows important in UI design?
    They improve appearance, highlight sections, and make interfaces modern and user-friendly.
  14. Real-life example:
    Product cards in shopping websites often use borders and shadows together to separate each item visually.
  15. Difference between normal CSS and Bootstrap utility classes:
    Normal CSS requires manual coding like border:1px solid black;, while Bootstrap uses ready-made classes like border shadow rounded.
