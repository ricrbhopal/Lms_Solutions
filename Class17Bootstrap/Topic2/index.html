Bootstrap Color Utilities

  1. What are Bootstrap color utilities?
    Bootstrap color utilities are predefined classes used to quickly apply text and background colors to HTML elements.
  2. Purpose of text color utility classes:
    They are used to change the color of text easily without writing custom CSS.
  3. Purpose of background color utility classes:
    They are used to set background colors for elements quickly.
  4. Syntax for text color utility classes:
    text-{color}
    Example: text-danger
  5. Syntax for background color utility classes:
    bg-{color}
    Example: bg-success
  6. Five common Bootstrap text color classes:
    text-primary, text-success, text-danger, text-warning, text-info
  7. Five common Bootstrap background color classes:
    bg-primary, bg-secondary, bg-success, bg-danger, bg-warning
  8. Why use light text on dark backgrounds?
    Light text improves readability and contrast on dark backgrounds.
  9. Use of text-white and text-dark classes:
    text-white makes text white, and text-dark makes text dark for better visibility.
  10. What does bg-opacity-* do?
    It controls the transparency level of background colors. Example: bg-opacity-50
  11. Purpose of bg-gradient class:
    It adds a gradient effect to the background color.
  12. How Bootstrap color utilities save time:
    They eliminate the need to write custom CSS for colors repeatedly.
  13. What happens if colors are chosen incorrectly?
    Poor color choices reduce readability and make the design unattractive.
  14. Real-life example:
    In an e-commerce website, product sale labels can use bg-danger text-white to highlight discounts.
  15. Difference between normal CSS and Bootstrap color classes:
    Normal CSS requires manual color coding like color:red;, while Bootstrap uses ready-made classes like text-danger.
