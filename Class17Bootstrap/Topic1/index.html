Bootstrap in Web Development

  1. What is Bootstrap in web development?
    Bootstrap is a popular open-source front-end framework used to create responsive and mobile-friendly websites quickly.
  2. Why do developers use Bootstrap instead of writing full CSS manually?
    Developers use Bootstrap because it saves time by providing ready-made styles and components.
  3. Three advantages of Bootstrap:
    1. Faster development
    2. Responsive design support
    3. Ready-made UI components
  4. Where is Bootstrap commonly used?
    It is used in business websites, e-commerce stores, blogs, dashboards, and portfolios.
  5. What is meant by front-end CSS framework?
    It means Bootstrap provides prewritten CSS and JavaScript tools for designing website user interfaces.
  6. How does Bootstrap help responsive design?
    Bootstrap uses grid systems and responsive classes that adjust layouts for different screen sizes.
  7. What is CDN in Bootstrap?
    CDN is an online hosted version of Bootstrap files used without downloading them.
  8. Steps to connect Bootstrap to HTML:
    - Create HTML file
    - Add Bootstrap CSS in head
    - Add Bootstrap JS before body closing tag
  9. Where should Bootstrap CSS link be placed?
    Inside the <head> section.
  10. Where should Bootstrap JavaScript be placed?
    Before closing </body> tag.
  11. What if internet is unavailable while using CDN?
    Bootstrap files will not load, and styles may not work.
  12. Difference between normal CSS and Bootstrap styling:
    Normal CSS requires manual coding, while Bootstrap uses predefined classes.
  13. Why is Bootstrap beginner-friendly?
    Because it is easy to learn and provides ready-made components.
