Bootstrap Text Alignment & Variants

  1. What is text alignment in Bootstrap?
    Text alignment in Bootstrap means positioning text to the left, center, or right using utility classes.
  2. What are text variants in Bootstrap?
    Text variants are utility classes used to control text alignment, transformation, wrapping, and styling.
  3. Purpose of text-start:
    Aligns text to the left side (default start position).
  4. Purpose of text-center:
    Aligns text in the center.
  5. Purpose of text-end:
    Aligns text to the right side.
  6. Difference between text-start, text-center, and text-end:
    text-start = Left align
    text-center = Center align
    text-end = Right align
  7. What does text-uppercase do?
    Converts all text into uppercase letters.
  8. What does text-lowercase do?
    Converts all text into lowercase letters.
  9. What does text-capitalize do?
    Capitalizes the first letter of each word.
  10. Difference between text-wrap and text-nowrap:
    text-wrap allows text to move to the next line.
    text-nowrap keeps text in a single line.
  11. Why are text alignment utilities useful?
    They quickly align text without writing extra CSS code.
  12. Why are text transformation classes better than custom CSS?
    They save time, reduce repeated coding, and make styling consistent.
  13. What happens if text-nowrap is used in a small-width container?
    Text may overflow outside the container instead of wrapping.
  14. Real-life example of text-center:
    Website headings, banners, and login page titles are commonly centered.
  15. Difference between normal CSS and Bootstrap text utilities:
    Normal CSS requires manual coding like text-align:center;, while Bootstrap uses ready-made classes like text-center.
